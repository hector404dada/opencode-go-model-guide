建议的 Agent 分工配置

在 ~/.config/opencode/opencode.jsonc 中按任务分配模型，避免高额度模型被琐事消耗：

// 日常主力用便宜量大的，攻坚时手动切
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode-go/deepseek-v4.1-flash",
  "agents": {
    "build":  { "model": "opencode-go/deepseek-v4.1-flash" },  // 写代码
    "plan":   { "model": "opencode-go/gpt-6-luna" },          // 规划
    "review": { "model": "opencode-go/kimi-k3.1-pro" }       // 审查攻坚
  },
  "permissions": [
    { "action": "edit", "resource": "*", "effect": "ask" },
    { "action": "bash", "resource": "*", "effect": "ask" }
  ]
}

避坑清单

⚠️ 15 个最容易踩的坑

  • DeepSeek 有峰谷价：V4.1 Flash 峰时 $0.30/$1.20（平时 $0.15/$0.60），V4 Pro 峰时 $1.32/$3.96 —— 周一至周五 01:00–04:00、06:00–10:00 UTC，批量任务尽量避开
  • DeepSeek 需要 Global 区域：V4.1 Flash / V4 Pro 默认只允许 Europe & US，必须在 Settings › Privacy 把 Regions 设为 Global 才能调用
  • Claude Haiku 5.5 上下文超 10 万就涨 5 倍（$0.1→$0.5 / $0.5→$2.5）—— 长 PDF 会翻车，改用 GPT-6 Luna
  • Gemini 4 Argon 五折只到 11/30（现 $2/$10，之后恢复 $4/$20），且输出上限只有 65,536；别按五折价做长期预算
  • Hy4 preview 输出上限只有 64,000，全场最低，却标着 1,024,000 上下文 —— 同价已有 Hy4，没有理由再用 preview
  • Grok 4.7 上下文超 20 万涨 2 倍（$2→$4 / $6→$12），且额度极紧（169 次/5h）
  • GLM-5.3 不支持图片，GLM-5.3-Flash 反而支持 —— 想看图别切到 GLM-5.3 主力版；两者都不支持 PDF
  • DeepSeek V4 Pro（攻坚模型）是纯文本 —— 想贴截图得换 Kimi K3.1 Pro、Hy4、GPT 6 Luna 或 Gemini 4 Argon
  • 能吃 PDF 的共 7 个：Gemini 4 Argon、Claude Haiku 5.5、GPT-6 Luna、GPT-5.6 Luna、Grok 4.7、Muse Spark 1.2 / 1.3（GLM-5.3-Flash 不在列）
  • 音频理解只有 6 个：Gemini 4 Argon、MiMo 全系（V2.5 / V2.6-Pro / V2.6-Flash）、Muse Spark 1.2 / 1.3
  • Muse Spark 1.3 / 1.2 仅限部分地区，且属于「允许用于训练的付费端点」，需在 Settings › Privacy 里开启对应区域才能调用
  • LongCat 2.5 Free 需 Global 区域：免费且支持图片，但不开 Global 就调不到；它和 Iceman、Beam 都是限时免费，随时可能下线
  • Beam Free 是纯文本且限地区 —— 额度不限，但在二十余个国家/地区不可用，别把长期流程绑在它上面
  • Kimi K3 每美元仅 7.3 次（Muse Spark 的 1/103），Gemini 4 Argon 五折期间也只有 14.7 次 —— 别拿它们跑批量
  • GLM-5.2 与 GLM-5.3 每美元请求都是 14.7 次，但能力低一档（AA Agentic 39.4 vs 53.4）—— 直接用 5.3
